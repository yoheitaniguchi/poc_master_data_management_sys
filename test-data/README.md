# 動作確認用テストデータ

SCR-1（CSV取込画面）の動作確認用に、各マスタ200件分のCSVサンプルデータを配置している。
アプリの配布物（`public/`配下）には含めず、手動でファイル選択して取り込むためのローカル用データ。

## ファイル一覧

| ファイル | 対象テーブル | 件数 |
|---|---|---|
| `m_item_200.csv` | 品目マスタ（m_item） | 200件 |
| `m_partner_200.csv` | 取引先マスタ（m_partner） | 200件 |

## データの特徴

- ヘッダー行は各テーブル定義JSON（`public/table-definitions/*.json`）の`columnId`と一致させている
  （`docs/design.md` §4.7の仕様どおり）
- 主キー（`item_code`/`partner_code`）は200件すべてユニーク
- `item_type`は「完成品／半製品／原材料」、`partner_type`は「得意先／仕入先」を仕様上の定数制約
  （`constants`）どおりに割り当て
- 任意項目（`notNull: false`）の`safety_stock`・`address`は一部の行をあえて空欄にし、
  未設定でも正常に取り込めることを確認できるようにしている
- 各カラムの`maxLength`制約を超える値は含めていない（正常系データのみ。バリデーションエラーの
  確認をしたい場合は、値を書き換えて意図的に制約違反を作ること）

## 使い方

1. `npm run dev`でアプリを起動
2. SCR-1（CSV取込画面）で対象テーブルを選択し、対応するCSVファイルを取り込む
3. SCR-2（マスタ検索・出力画面）で200件が検索・表示できることを確認
4. SCR-3（取込実行ログ画面）で成功件数200件のログが記録されていることを確認
